====================================================
  ETSY BULK LISTING — HƯỚNG DẪN SỬ DỤNG
====================================================

CẤU TRÚC FOLDER:
-----------------
Etsy/
  _TEMPLATE/          ← Mẫu gốc, đừng xóa
    images/           ← Ảnh preview listing
    info.txt          ← Thông tin sản phẩm

  product-01/         ← Sản phẩm 1
    images/
    info.txt

  product-02/         ← Sản phẩm 2
    images/
    info.txt

  (thêm product-04, product-05... khi cần)


CÁCH THÊM SẢN PHẨM MỚI:
-------------------------
1. Copy toàn bộ folder "_TEMPLATE" → đổi tên thành "product-04" (hoặc tên sản phẩm)
2. Mở file "info.txt" → điền đầy đủ thông tin
3. Cho ảnh preview vào folder "images/"
4. Nói với Claude: "Đăng product-04 lên Etsy"


CÁCH ĐĂNG HÀNG LOẠT:
----------------------
Nói với Claude: "Đăng tất cả sản phẩm chưa được đăng lên Etsy"
Claude sẽ lần lượt đọc từng folder và đăng lên Etsy qua Chrome.


LƯU Ý:
-------
- Đảm bảo đã đăng nhập Etsy trên Chrome trước khi bắt đầu
- Mỗi listing cần ít nhất 1 ảnh
- Tags tối đa 13 từ/cụm từ, cách nhau bằng dấu phẩy
